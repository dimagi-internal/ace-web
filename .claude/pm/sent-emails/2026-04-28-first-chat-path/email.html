What's new in ace-web

If you've signed in for the first time, you no longer have to play detective to figure out how to start a chat. We tightened three concrete dead-ends along the new-user path — empty-state CTAs, an actionable inline message when Claude CLI isn't connected, and a clearer "how do I connect?" page that finally mentions the easy option.

Highlights

Inline "Connect Claude CLI" callout above the chat box

The placeholder text used to read Claude CLI not connected — visit /auth/cli to enable chat, but the path lived inside a textarea so you couldn't click it. Replaced with a real amber callout sitting directly above the input, with a clickable Connect now → link.

After: amber strip with clickable "Connect now →" link directly above the input.

Try it: https://labs.connect.dimagi.com/ace/chat in a session where the server doesn't have CLI credentials yet.

Connect Claude CLI page now leads with the easy path

Used to push the python-script flow first, which assumes you have the repo checked out and python ready. Now leads with /ace-web:create-cli-credentials (a Claude Code slash command, one line) and keeps the script as the fallback. The disconnected-state copy stops being operator-speak and starts being user-friendly.

After: friendly "Not connected" copy + Option 1 (Claude Code skill, marked easiest) and Option 2 (python script) boxes.

Try it: https://labs.connect.dimagi.com/ace/auth/cli

Sessions tab empty-states stop being a one-line dead-end

The active-empty branch now has a real Start a chat button. The imported-empty branch has its own Upload .jsonl CTA. The archived-empty branch finally says "No archived sessions." instead of the misleading "No sessions yet — start a chat" the old code shipped on every empty filter.

After: the Archived tab now correctly says "No archived sessions." instead of the old misleading active-tab copy. The active-empty branch (not screenshot-able for an account with existing chats) similarly gains a Start a chat button.

Try it: https://labs.connect.dimagi.com/ace/sessions — click the Archived or Imported tab if you don't have rows there.
