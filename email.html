"Thinking…" stays put until the first token

The bouncing-dots indicator used to vanish the moment the WebSocket reported a stream had started, leaving a single 1px cursor floating in an otherwise-empty bubble for the 100–300ms before any actual text arrived. That window felt like the chat had stuttered. Now Thinking… persists smoothly until the first character of the response shows up, so the visual hand-off is continuous.
