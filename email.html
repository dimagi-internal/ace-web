Chats know which opp they belong to.

The chat side of ace-web stopped pretending opps don't exist. Step-seeded chats now show their opp + step in the header, the recent-chats sidebar groups by opp, and the Sessions page can filter to "all chats about opp X."

Chat header shows the linked opp + step

Open any chat that was launched via "Discuss in chat" on a Workbench step (or imported via /ace:run --ace-web-url). The header now reads Discussing <opp> · <step> with a one-click link back to the Workbench. Plain web-native chats render the existing header unchanged.

After: the breadcrumb appears above the chat title, with both opp and step linked back to the Workbench.

Recent-chats sidebar groups by opp

Instead of a flat 10-deep list, the sidebar buckets your chats by opp — each opp gets its own header (clickable to the Workbench), with unlinked chats falling under "Other chats". Falls back to the flat list when no chats are opp-linked, so the change is invisible until you start using "Discuss in chat".

After: each opp's chats are bucketed under a small uppercase header. Click the header to jump to the Workbench.

Try it on labs →

Filter the Sessions page by opp

Alongside the existing Active / Archived / Imported chips, there's now an Opp dropdown that narrows the list to chats linked to a particular opp. Each row picks up a small opp: <name> badge so you can scan the opp without expanding the row.

After: the new Opp dropdown narrows the list, and each row shows a small opp badge alongside the source/archived chips.
